Overview

The lab delivers media, home automation, DNS, and household web apps from hardware I administer myself. The main host is an Apple Mac mini (M2, 8 GB) running macOS. Docker Desktop provides a memory-capped Linux VM for most services. Plex, a local LLM runtime (Ollama), and a custom FastAPI command center run natively. A Raspberry Pi 5 hosts a companion command-center project and is reachable only over the mesh VPN.

The design priority is least-privilege remote access. Admin interfaces listen on localhost and are reachable only through Tailscale. The public internet sees just two small, PIN-protected pages.

Services by category

Access & DNS

Tailscale mesh VPN for all administration; AdGuard Home as the household DNS resolver, with its admin UI kept off the LAN.

Platform

Docker Desktop (memory-capped Linux VM), Docker Compose stacks, Portainer, and macOS launchd for native services and schedules.

Command centers

A custom FastAPI progressive web app as the lab dashboard, a companion app on the Pi, and a Discord bot backed by a local LLM (Ollama).

Home automation

Home Assistant with a Matter bridge, a local voice pipeline (Whisper, Piper, openWakeWord), NFC tag automations, and TV integrations.

Media & files

Plex Media Server with an automated request-and-organize pipeline (Radarr, Sonarr, Prowlarr, Bazarr), Immich for photos, and File Browser.

Household apps

Vaultwarden (password manager), Mealie (meals and grocery lists), and a few custom web apps I built.

Observability

Uptime Kuma, Prometheus, Grafana, node and container exporters, and a WAN speed tracker.

Alerting & automation

Self-hosted ntfy push alerts, launchd jobs for backups and reports, and an auto-healing watchdog.

Backups

Nightly consistent snapshots of container data, config copies rotated to the Pi, and restic for local and offsite backups.

Security approach

  • Localhost binding. Admin and app UIs listen only on localhost on the host. That includes Home Assistant, DNS admin, Grafana, Portainer, and the media consoles.
  • Mesh VPN for admin. Tailscale is the only way to reach those consoles, at home or away. I don't forward any ports for admin interfaces.
  • Small public surface. Tailscale Funnel exposes only two small, PIN-protected pages. Those apps still bind to localhost, with forwarded-header controls on the proxy path.
  • Split DNS. AdGuard Home serves the LAN while its own admin page stays VPN-only.
  • Secrets hygiene. Credentials live in a self-hosted password manager and stay out of logs, chat, and alerts. The auto-heal alerts scrub secrets before sending.

New: self-healing containers auto-heal

A Python watchdog run by launchd every 3 minutes. It checks the lab's containers and repairs failures on its own, carefully.

  • Triggers when a container is unhealthy or crashed, or when Uptime Kuma reports it down 3 checks in a row.
  • Restarts only containers on an allowlist, once, then verifies the container actually came back.
  • Rate limited to one restart per container per hour. It never undoes a container I stopped on purpose.
  • Sends an ntfy push with before and after logs, scrubbed of secrets.
  • Skips services that are intentionally off, and has a one-file pause switch.
every 3 min (launchd)
 └─ for each allowlisted container
     ├─ healthy?            → skip
     ├─ stopped by me?      → skip
     ├─ restarted < 1h ago? → skip + alert
     └─ unhealthy / exited / Kuma down x3
         ├─ capture logs (before)
         ├─ docker restart  (once)
         ├─ verify running + healthy
         ├─ capture logs (after)
         └─ ntfy push  (secrets scrubbed)

Problems I've solved

Problem

Remote Home Assistant access broke after an upstream change stopped honoring YAML proxy settings.

Fix

Applied trusted-proxy settings in the running HTTP configuration and restored VPN access without exposing the UI publicly.

Problem

A secondary DNS resolver stalled clients whenever its host was offline.

Fix

Removed it from the VPN nameserver list so queries failed over cleanly to the primary, and documented how to re-add it.

Problem

Copying live Docker volumes (including SQLite databases) with a plain archive risks corrupt backups.

Fix

Wrote snapshot tooling that uses a temporary container sharing the service mounts, so backups stay consistent without restarts.

Problem

An 8 GB host will swap or run out of memory if every stack runs at once.

Fix

Capped the Docker VM near 4 GB, scheduled the photo library overnight, and kept heavy ML workloads off. Media and automation stay up.

Problem

Containers that crash overnight stay down until someone notices.

Fix

Built the allowlisted auto-heal watchdog with verification, rate limits, and secret-scrubbed alerts.
